Steps:
1) npm install
2) npm run dev
3) Open http://localhost:5173

Expected:
- Each Monaco gutter row shows the actual line number plus an extra “1” overlay.
- Comment out @import "tailwindcss"; in src/style.css and restart dev server; the ghost
  numbers disappear.
The editor runs with the vs-dark theme so the repro matches the dark UI.

Notes:
- Monaco CSS is bundled locally via
  `import "monaco-editor/min/vs/editor/editor.main.css";` in src/main.js so Vite/Tailwind
  process vendor styles instead of CDN-loading them.
- index.html includes a hidden `<div class="list-item">` to force Tailwind to emit the
  list-item utility rules that introduce `content: counter(line-number)`.
